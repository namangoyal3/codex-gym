CODEX GYM

Your project is a training base. Your Codex agent is the athlete.

  1. Every folder is a training station. Source code gets a power rack, tests get a bank of treadmills, config gets a dumbbell rack, docs get a stretch studio, markup gets a boxing ring. The number on the sign is how many files are inside; the bigger and more loaded the station, the more code it holds.
  2. Tap a station to put the agent to work there. Add tests, document it, break it up, tidy it. You never write a prompt — the base does that for you.
  3. Watch it train. The athlete walks to the station it is working on. Writing a file is a deadlift, running tests is a sprint, reading code is walking the floor, and a failed command is a missed rep.
  4. Stamina is its memory. It drains as the job gets longer and comes back when the agent clears its head.
  5. PROJECT shows where you are — from PLANNED all the way to SHIPPED — read live from git and from whether your tests pass.

No project yet? Press + NEW and it builds you a real one to train on. Drag to pan, scroll to zoom.
